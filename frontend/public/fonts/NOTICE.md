# Bundled Font Notices

The following files are bundled with ChatPDF for offline Chinese typography. Their full license texts are in `fonts/licenses/` in the packaged frontend output.

| Font | Source | License file |
| --- | --- | --- |
| Source Han Sans SC | [Adobe source-han-sans](https://github.com/adobe-fonts/source-han-sans) | `source-han-sans-OFL-1.1.txt` |
| Source Han Serif SC | [Adobe source-han-serif](https://github.com/adobe-fonts/source-han-serif) | `source-han-serif-OFL-1.1.txt` |
| LXGW WenKai | [lxgw/LxgwWenKai](https://github.com/lxgw/LxgwWenKai) | `lxgw-wenkai-OFL-1.1.txt` |
| LXGW Neo XiHei | [lxgw/LxgwNeoXiHei](https://github.com/lxgw/LxgwNeoXiHei) | `lxgw-neo-xihei-IPA-license.txt` |
| Sarasa UI SC | [be5invis/Sarasa-Gothic](https://github.com/be5invis/Sarasa-Gothic) | `sarasa-ui-sc-OFL-1.1.txt` |
| Clear Han Serif (屏显臻宋) | [izfsk-ium/Clear-Han-Serif](https://github.com/izfsk-ium/Clear-Han-Serif) | `clear-han-serif-OFL-1.1.txt` |
| LXGW 975 Yuan | [lxgw/975Yuan](https://github.com/lxgw/975Yuan) | `975-yuan-OFL-1.1.txt` |

OPPO Sans is requested from OPPO's official Webfont endpoint only when selected. Alibaba PuHuiTi, Hanyi WenHei, GWM Sans, and CangEr WenKai remain system-font options because their redistribution terms were not verified for bundling with this application.
